- Full simulator source (`setup_params.py`, `optics.py`, `simulate.py`, …) and registered YAML profiles A–D / `C_lab`
- Publication scripts for Figures 3–6 under `tools/`
- Figure 6(a) **derived** experimental frequency records (accepted-center counts and plotted frequencies) and validation references under `reproducibility/figure6a/reference/`
- Independently computed Figure 6(a) outputs under `reproducibility/figure6a/computed/` (regenerated by `--compute`)
- Corrected Supplementary Table S3 caption wording: `reproducibility/figure6a/reference/TABLE_S3_CAPTION_CORRECTION.md` (full-precision crest-position / peak-selection audits are **not** public)
- Architecture identity helpers (`verification/configuration_identity.py`)
- Hash manifest `SHA256SUMS.txt` and audit `COMMENT_A2_TECHNICAL_AUDIT.md`

## Restricted (not publicly available)

The original experimental EMCCD TIFF images
used for Figures 5–6 are not publicly available.

The derived experimental measurements and
associated analysis documentation are
available through the public GitHub repository.

The public repository does not include
the original experimental TIFF recordings.

## What a clean checkout can reproduce without original TIFFs

```bash
python tools/reproduce_figure6a.py --compute   # independent simulation + figure
python tools/reproduce_figure6a.py --verify    # compare computed vs reference (read-only)
# or:
python tools/reproduce_figure6a.py --public    # compute then verify
```

Simulation image strips and frequencies are generated from the production model.
Experimental **frequency** markers use the shipped derived Table S3 record.
Experimental **image** panels require the original TIFF archive (not public).

## Scope claim (do not overstate)

This package is a **prototype / pre-validation** physics-informed forward simulator.
Software verification and semi-quantitative experimental correspondence are
documented; the work does **not** claim absolute experimental calibration or a
fully validated closed-loop digital twin.
